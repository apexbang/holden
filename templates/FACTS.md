# Phase NNN facts

Every fact the grill looked up, one entry each, with the file or URL that owns it. The
settled tree cites entries, never bare claims; a claim with no entry is a question. The
researcher re-verifies each entry before the code and marks it confirmed or contradicted.

A fact about how a framework, runtime or browser behaves (load order, what `history.length`
counts, what a navigation leaves in the back-forward list) cites one of:
- that platform's spec or docs at a URL
- its installed source at `path:line`
- a probe's command and output

The app's own code shows only what the app asks for. A behaviour with none of these is a `Needs from the world`
line naming the device walk or test that settles it, and the researcher confirms it against the
same kind of source.
